# Math Game

Projeto Flutter completo baseado no código enviado, com jogo, cronômetro, níveis, streak, recorde salvo no aparelho, teclado numérico e suporte a teclado físico.

## Gerar o APK

No computador com Flutter instalado, dentro desta pasta:

```text
flutter pub get
flutter build apk --release
```

O APK será criado em:

```text
build/app/outputs/flutter-apk/app-release.apk
```
